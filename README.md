# Space Weather Risk Monitor Frontend

Space Weather Risk Monitor is a Vue-based dashboard for monitoring daily space weather conditions and their potential impact on critical infrastructure. The application consumes assessments generated from NASA DONKI data and presents infrastructure risk scores, solar activity observations, and historical risk trends through a clean, responsive interface.

## Core Features

### Daily Infrastructure Risk Dashboard

The dashboard presents the latest space weather assessment with an overall threat level and separate heuristic risk scores for GPS disruption, power grid impact, and radio blackout risk.

### Solar Activity Monitoring

The application displays the solar activity recorded for each assessment date, including solar flare counts, coronal mass ejection counts, peak flare classification, and primary CME characteristics.

### Historical Risk Trends

Users can switch between 7-day and 30-day views to examine how overall infrastructure risk has changed over time. Chart.js is used to render the historical risk trend and provide a visual comparison of daily assessments.

### Responsive Component-Based Interface

Built with Vue 3 and TypeScript, the frontend is structured into focused components for the dashboard header, assessment overview, risk scores, solar activity, and risk trends. The interface is responsive across desktop and mobile screen sizes.

### Backend API Integration

The frontend communicates with a lightweight FastAPI backend that provides the latest assessment and historical trend data through REST API endpoints. Assessment data is loaded asynchronously when the dashboard is initialized.

## Risk Assessment

The frontend displays risk scores generated by the backend using observed space weather data from NASA DONKI.

The dashboard provides four heuristic risk scores:

    Overall Risk
    GPS Disruption
    Power Grid
    Radio Blackout

The scores are application-derived estimates used to communicate relative infrastructure risk. They are not probabilities and do not represent direct measurements of infrastructure impact.

The overall risk score represents the highest estimated risk across the monitored infrastructure categories.

### Risk Inputs

The risk model incorporates observed solar activity and CME characteristics, including:

- Solar flare intensity
- Solar flare counts
- CME speed
- CME half-angle
- Earth-directed CME status

An Earth-directed CME is treated as a potential contributing factor within the application's heuristic model, but it does not guarantee that an impact on Earth will occur.

## Performance & Reliability

The frontend is designed to remain lightweight by combining:

- Vue component-based rendering
- Asynchronous API requests
- Lightweight Chart.js visualizations
- A simple REST API architecture
- Server-side data processing through the backend

The latest assessment and trend history are requested in parallel when the dashboard loads.

## Data & Limitations

Space weather observations are sourced from NASA DONKI and processed by the backend ingestion pipeline.

The dashboard represents daily assessments rather than continuously updated real-time conditions. Risk scores are heuristic estimates created for this project and should not be interpreted as operational forecasts, probabilities, or guaranteed predictions of infrastructure impact.

The application is intended as a portfolio project demonstrating API integration, data visualization, frontend architecture, and space weather risk modeling.

## Security

The frontend does not contain database credentials or directly access Supabase. All database access is handled by the backend API.

The application is publicly accessible and does not require user accounts or authentication.
